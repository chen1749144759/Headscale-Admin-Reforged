## О проекте

**ScaleForge** — это **полная переработка** [arounyf/Headscale-Admin-Pro](https://github.com/arounyf/Headscale-Admin-Pro) v4.0.0.

Оригинальный проект был монолитным приложением на Flask + Jinja2. Этот проект полностью перестроен с современной архитектурой **разделения фронтенда и бэкенда**: FastAPI предоставляет REST API на бэкенде, а Vue 3 работает как SPA на фронтенде — всё это в совершенно новом тёмном стекломорфном интерфейсе.

### Благодарности и происхождение

Этот проект является форком [arounyf/Headscale-Admin-Pro](https://github.com/arounyf/Headscale-Admin-Pro) тега 4.0.0. Особая благодарность **arounyf** за оригинальную работу.

## Технологический стек

| Уровень | Технология |
|---------|------------|
| Бэкенд | Python 3.13 + FastAPI + Uvicorn |
| Фронтенд | Vue 3 + Vite + Element Plus + Pinia + Vue Router 4 |
| Аутентификация | JWT + нативный bcrypt (совместимость с Python 3.13 + bcrypt 5.x) |
| База данных | PostgreSQL 16 (Docker) / SQLite (локальная разработка) |
| Headscale | [Headscale-Admin-AE](https://github.com/chen1749144759/Headscale-Admin-AE) (расширенная версия) |
| Ретранслятор DERP | Автономный [derper](https://pkg.go.dev/tailscale.com/cmd/derper) с автоматически генерируемым самоподписанным TLS-сертификатом |

## Возможности

- **Панель управления** — Мониторинг CPU/памяти/трафика в реальном времени с плавными графиками трендов, статистика узлов
- **Управление группами** — Управление пространствами имён пользователей Headscale, квоты машин, шаблоны ACL-правил
- **Управление узлами** — Список, поиск, фильтрация, переименование, удаление, управление тегами (forcedTags)
- **Управление маршрутами** — Маршруты подсетей, одобрение/отзыв, редактор autoApprovers, выходные узлы
- **Редактор ACL-правил** — Поддержка HuJSON, форматирование, номера строк, синхронизация в режиме базы данных
- **Управление предварительными ключами** — Создание/удаление, копирование в один клик
- **Ретранслятор DERP** — Приватный автономный DERP-сервер с автоматическим TLS, развёртывание без настройки
- **Системные настройки** — Конфигурация подключения, API-ключ, политика регистрации, блокировка безопасности
- **Журналы операций** — Постраничный аудиторский след с читаемыми именами
- **Мониторинг состояния** — Статус подключения headscale в реальном времени в верхней панели

## Быстрый старт (Docker Compose)

Самое простое развёртывание — одна команда запускает все сервисы (PostgreSQL + Headscale AE + Ретранслятор DERP + Бэкенд панели + Nginx).

### Предварительные требования

- Linux-сервер (рекомендуется Ubuntu 22/24)
- Docker + Docker Compose

```bash
# Установите Docker при необходимости
curl -fsSL https://get.docker.com | sh
```

### Шаг 1: Загрузка

```bash
mkdir -p ~/headscale-admin && cd ~/headscale-admin

# Загрузите docker-compose.yml и файлы шаблонов
for f in docker-compose.yml config.yaml.tmpl derp.yaml.tmpl entrypoint.sh .env.example; do
  curl -fsSL -o "$f" \
    "https://raw.githubusercontent.com/chen1749144759/ScaleForge/main/docker/$f"
done
chmod +x entrypoint.sh
```

### Шаг 2: Настройка .env

```bash
cp .env.example .env
```

Отредактируйте `.env` и задайте **как минимум**:

```bash
# ОБЯЗАТЕЛЬНО — Публичный IP или домен вашего сервера
HEADSCALE_SERVER_URL=http://ВАШ_ПУБЛИЧНЫЙ_IP:8080

# ОБЯЗАТЕЛЬНО — Публичный адрес ретранслятора DERP (обычно совпадает)
DERP_DOMAIN=ВАШ_ПУБЛИЧНЫЙ_IP
```

> **Важно**: `HEADSCALE_SERVER_URL` должен быть доступен для клиентов Tailscale. Если вы измените `HS_PORT`, соответствующим образом обновите порт в URL.

### Шаг 3: Запуск

```bash
docker compose up -d
```

При первом запуске автоматически загружаются образы, генерируются TLS-сертификаты для DERP и запускаются все сервисы в правильном порядке с проверками работоспособности.

### Шаг 4: Проверка

```bash
docker compose ps   # Всё должно показывать healthy/Up
```

| Адрес | Назначение |
|-------|------------|
| `http://ВАШ_IP` | Панель администратора |
| `http://ВАШ_IP:8080` | API Headscale (подключение клиентов) |

### Шаг 5: Создание администратора

Откройте `http://ВАШ_IP` в браузере. **Первый зарегистрированный пользователь становится администратором** (после этого регистрация закрывается).

### Порты файрвола

| Порт | Протокол | Назначение |
|------|----------|------------|
| 80 | TCP | Веб-панель администратора |
| 8080 | TCP | API Headscale + протокол Noise |
| 3478 | UDP | STUN (обход NAT) |
| 3479 | TCP | Ретранслятор DERP (шифрование TLS) |

### Основные команды

```bash
# Остановить все сервисы
docker compose down

# Обновить образы и перезапустить
docker compose pull && docker compose up -d

# Просмотр журналов
docker compose logs -f --tail=50

# Резервное копирование базы данных
docker exec hs-postgres pg_dump -U headscale_admin headscale_admin > backup.sql

# Создать API-ключ вручную
docker exec hs-headscale headscale apikey create
```

### Сохранность данных

Все данные сохраняются через Docker-тома — `docker compose down` не приводит к потере данных:

- `postgres-data` — База данных
- `headscale-data` — Данные выполнения Headscale + API-ключ
- `derper-certs` — TLS-сертификаты DERP-сервера

Для полного сброса: `docker compose down -v` (**данные не подлежат восстановлению**).
