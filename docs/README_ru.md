# Документация ScaleForge

Эта устаревшая версия документации выведена из использования по соображениям безопасности. Старый процесс регистрации и команды клиента не соответствуют текущей архитектуре учетных записей и паролей.

Актуальная документация находится в [корневом README](../README.md). В ней описаны архитектура, вход, приватные Unix-сокеты, CAPTCHA, DNS, подписанные OTA-обновления, миграции базы данных и обновление системы.

Новые клиенты используют `scaletail login --username ...`. Для автоматизации разрешен только `--password-file` с правами файла `0600`.
